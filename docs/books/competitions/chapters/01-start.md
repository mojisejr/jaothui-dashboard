## เล่มนี้ช่วยให้ทำอะไรได้

พาทีมงานใหม่รู้จักการตั้งค่างาน ตรวจรุ่นแข่งขัน และแยกขั้นพิจารณาใบสมัครออกจากการส่ง LINE หน้าตัวอย่างทั้งสี่ใช้ภาพระบบจริงกับข้อมูลจำลอง เพื่อทดลองขนาดอักษรและภาพก่อนจัดทำคู่มือเต็มเล่ม

## เส้นทางของทีมงาน

![ภาพรวมการทำงาน](asset:workflow)

1. **สร้างร่าง** ใส่รายละเอียด วันจัดงาน และชุดรุ่น ตรวจให้ครบก่อนเผยแพร่
2. **เปิดรับสมัคร** ผู้สมัครใช้ Jaothui Event และ LINE ตามเดิม ทีมงานตรวจใบสมัครใน dashboard
3. **พิจารณาและแจ้งผล** บันทึกอนุมัติหรือไม่อนุมัติ แล้วกดส่ง LINE แยกอีกขั้น
4. **ปิดงานและส่งออก** ตรวจข้อมูลล่าสุด ก่อนส่ง Excel หรือใบสมัคร Word ให้ผู้เกี่ยวข้อง

> **ปิดรับสมัคร ไม่เท่ากับปิดงาน**\
> ปิดรับสมัครหยุดผู้ใช้ทั่วไป แต่เจ้าหน้าที่อาจลงทะเบียนหน้างานต่อได้ตามช่วงเวลาของงาน การปิดงานหยุดทั้งสองทาง

## ก่อนเริ่มงานจริง

ใช้บัญชีทีมงานที่ได้รับมอบหมาย ยืนยันชื่องานทุกครั้ง และเริ่มจากสถานะร่าง ข้อมูลตัวอย่างในเล่มนี้ไม่ใช่ผลพิจารณาหรือการส่งข้อความถึงผู้สมัครจริง
