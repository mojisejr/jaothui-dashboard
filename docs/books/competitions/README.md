# คู่มือการแข่งขัน: ตัวอย่างรูปเล่ม

Issue #62. `preview.pdf` เป็นตัวอย่าง 4 หน้าเพื่อทบทวนภาษาไทย ขนาดภาพ
และรูปแบบการอธิบาย ยังไม่ใช่คู่มือการแข่งขันฉบับเต็ม

แก้เนื้อหาใน `chapters/*.md`, ข้อมูลเล่ม/ลำดับบทใน `book.json` และภาพที่ผ่าน
การตรวจใน `assets/screenshots` สร้างซ้ำด้วยคำสั่งใน
[`scripts/book-publish/README.md`](../../../scripts/book-publish/README.md)

ภาพต้องมาจาก UI จริงกับข้อมูลจำลอง และมีที่มาใน `capture-manifest.json`
อย่าใช้ผู้สมัครจริง ภาพที่มีเบอร์โทรหรือ credential และอย่าเผยแพร่งาน QA
ใน production เพื่อถ่ายภาพประกอบหนังสือ

การบันทึกผลพิจารณากับการส่ง LINE เป็นคนละขั้นตอน ตัวอย่างสถานะในเล่ม
ไม่ใช่การยืนยันว่ามีการส่งข้อความจริง

ก่อนส่งต่อ ตรวจ PNG ทุกหน้าที่ขนาดพิมพ์ A4 จริง จากนั้นให้ผู้เริ่มใช้ใหม่
ลองทำตาม การตรวจโครงสร้าง PDF อย่างเดียวไม่ยืนยันว่าอ่านแล้วทำได้

ผลตรวจตัวอย่างเล่มนี้อยู่ใน [VALIDATION.md](VALIDATION.md)

## คู่มือเต็มฉบับทบทวน 0.2

เนื้อหาเต็มอยู่ใน `full-chapters/*.md` เรียงด้วย `manual.json` แยกจากตัวอย่าง
4 หน้าเดิม ใช้ปก/สารบัญแยกรวม 25 หน้า ครอบคลุมเข้าใช้ สร้างงาน
รุ่น/อายุ เผยแพร่ ใบสมัครทั่วไป/Royal บันทึกผล ส่ง LINE หน้างาน ปิดงาน
ส่งออก การกู้จากข้อผิดพลาด และภาคผนวกผู้ดูแลที่มีเฉพาะชื่อตัวแปร

```sh
.tmp/book-publish-venv/bin/python scripts/book-publish/publish.py \
  --book docs/books/competitions/manual.json
.tmp/book-publish-venv/bin/python scripts/book-publish/publish.py \
  --check docs/books/competitions/jaothui-competition-manual.pdf
```

ภาพเต็มชุดใหม่มีที่มาใน `capture-manifest-full.json` และแยกจากภาพตัวอย่างเดิม
เก็บไฟล์ภาพเต็มจาก Browser ตาม byte จริง กรอบ SVG เป็นเลเยอร์เอกสารที่เลือก
เฉพาะแผงให้ตัวหนังสืออ่านได้ ไม่เขียน UI ใหม่ทับภาพ ภาพแต่ละกรอบและต้นฉบับ
ต้องประกาศใน manifest เพื่อบันทึก hash ของข้อมูลภาพที่ใช้จริงทั้งหมด

แหล่งยืนยันคำสั่งและข้อมูลตัวอย่างอยู่ใน
[SOURCE-TRUTH-CHECKLIST.md](SOURCE-TRUTH-CHECKLIST.md) ตรวจรูปเล่มครบ 25 หน้าแล้ว
ผลและข้อจำกัดอยู่ใน [VALIDATION-FULL.md](VALIDATION-FULL.md) ขั้นถัดไปคือให้
ผู้ไม่เคยใช้ทดลองอ่าน/ทำตามก่อนอ้างการยอมรับสำหรับผู้เริ่มต้น

ไฟล์เป็น A4 แนวตั้ง เลือกพิมพ์ขนาดจริง 100% และตรวจตัวอย่างก่อนพิมพ์ทั้งเล่ม
ยังไม่ได้ทดสอบกระดาษจริงในรอบนี้ จึงควรลองหนึ่งหน้าที่มีภาพหน้าจอก่อน
