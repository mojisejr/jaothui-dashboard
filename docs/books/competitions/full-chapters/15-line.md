## เริ่มหลังบันทึกผลแล้ว
ตรวจ **ผลการส่ง LINE** ใต้ส่วนอนุมัติ ต้องมีผลพิจารณา ผู้รับ LINE และระบบเปิดการส่งก่อน ปุ่มส่งจึงใช้งานได้

![สถานะส่งแยกจากผลพิจารณา](asset:review-line)

1. ตรวจผลอนุมัติ/ไม่อนุมัติให้ถูก แล้วกด **ส่ง / ลองส่ง LINE** หนึ่งครั้ง
2. รอให้ทำงานจบ อ่านสถานะในส่วนนี้ ไม่กดบันทึกอนุมัติซ้ำเพื่อหวังส่งใหม่
3. เมื่อขึ้น **LINE รับคำขอส่งแล้ว** หมายถึงผู้ให้บริการรับคำขอ ไม่ยืนยันว่าผู้สมัครได้รับหรือเปิดอ่านแล้ว

| สถานะที่พบ | ควรทำต่อ |
|---|---|
| บันทึกผลแล้ว • ยังไม่ได้ส่ง LINE | ตรวจผลแล้วใช้ปุ่มส่ง |
| ส่ง LINE ไม่สำเร็จ | ตรวจสาเหตุแล้วใช้ปุ่มลองส่ง |
| ยังยืนยันผลส่ง LINE ไม่ได้ / ต้องตรวจผลการส่งก่อนลองใหม่ | หยุดกดซ้ำ ให้ผู้ดูแลตรวจ |
| ไม่มีผู้รับ LINE สำหรับใบสมัครนี้ | ไม่ส่งเข้าบัญชีทีมงานแทน |

ภาพในเล่มถ่าย local/dev โดย **ปิดการส่ง LINE จริง** จึงไม่ใช่หลักฐานส่งถึงคนจริง ถ้าระบบแจ้ง **ระบบปิดการส่ง LINE อยู่ บันทึกผลการตรวจได้ตามปกติ** ให้เก็บผลไว้และแจ้งผู้ดูแล ไม่เปิดสวิตช์เอง
