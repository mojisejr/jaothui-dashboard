## แยกอาการแล้วทำทีละอย่าง
หากมีทีมหลายคนใช้บัญชีร่วม งานหรือใบสมัครอาจถูกแก้ระหว่างที่คุณเปิดหน้าอยู่ คำเตือนไม่ได้แปลว่าข้อมูลหายเสมอไป

| อาการ | วิธีรับช่วง |
|---|---|
| ข้อมูลถูกเปลี่ยน / บันทึกชนกัน | ใช้ **โหลดข้อมูลล่าสุด** แล้วตรวจความต่างก่อนบันทึก |
| ฟอร์มงานมีข้อมูลยังไม่บันทึก | จดค่าที่จำเป็นก่อนโหลดใหม่ เพราะอาจทิ้งค่าที่แก้ |
| หน้าตรวจใบสมัครโหลดล่าสุด | ข้อความที่กำลังกรอกยังอยู่ ต้องเทียบผลล่าสุดก่อนบันทึก |
| หน้างานยังยืนยันผลไม่ได้ | ใช้ **ลองคำขอเดิมอีกครั้ง** รักษารายการเดิม |
| ผลอนุมัติสำเร็จ แต่ LINE มีปัญหา | ตรวจสถานะส่งแยก ไม่อนุมัติซ้ำเพื่อส่งใหม่ |
| โหลดรายการไม่สำเร็จ | ใช้ปุ่มลองโหลดของหน้านั้น ตรวจเครือข่าย |

## ส่งเรื่องให้ผู้ดูแลแบบที่ตามได้
แนบ **ชื่องาน รหัสงาน รหัสใบสมัคร เวลาไทย ขั้นตอนก่อนเกิดปัญหา และข้อความผิดพลาด** ถ่ายเฉพาะส่วนจำเป็น ปิดบังข้อมูลส่วนบุคคลที่ไม่เกี่ยวข้อง ไม่ส่งรหัสผ่าน key หรือ token

เมื่อเป็นข้อมูลกติกาที่ล็อกหลังมีผู้สมัคร ให้คุณนนท์ตรวจรายงานผลกระทบ ไม่แก้ฐานข้อมูลตรง ไม่เปิด admin เก่ากลับ และไม่เปลี่ยนวันเกิดเพื่อทำให้รุ่นผ่าน

## เมื่อกลับมาใช้ได้
เปิดรายการเดิม ตรวจว่าผลก่อนหน้าบันทึกไปแล้วหรือไม่ แล้วทำเฉพาะขั้นที่ยังไม่สำเร็จ หากสถานะ LINE ไม่แน่ชัดหรือต้องตรวจผล ให้รอผู้ดูแลตรวจ อย่ากดส่งรัว ๆ
