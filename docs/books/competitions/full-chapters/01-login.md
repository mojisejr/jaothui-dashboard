## ก่อนเริ่ม
ขอชื่อบัญชีและรหัสผ่าน Dashboard จากคุณนนท์ผ่านช่องทางภายใน เตรียมอินเทอร์เน็ตและเปิดคอมพิวเตอร์ ไม่ต้องสมัครบัญชี LINE ใหม่เพื่อเข้าหลังบ้าน

1. เปิด [dboard.jaothui.com](https://dboard.jaothui.com/) กรอกช่อง **username** และ **password** แล้วกด **Login**
2. ไปที่ [หน้าจัดการการแข่งขัน](https://dboard.jaothui.com/dashboard/competitions) ตรวจหัวข้อ **จัดการการแข่งขัน**
3. เลือกงาน แล้วใช้เมนู **ตั้งค่างาน**, **ใบสมัคร**, **ลงทะเบียนหน้างาน**, **ส่งออกข้อมูล** ตามหน้าที่

![ทางเข้าหลังบ้าน](asset:login)

## จุดที่ต้องจำ
บัญชีรอบนี้เป็น **บัญชีทีมงานร่วม** สำหรับทีมภายในดูแลทุกงาน ระบบยังไม่แยกสิทธิ์รายคน และไม่สามารถยืนยันได้ว่าบุคคลใดกดปุ่มจากบัญชีนี้ ควรแจ้งกันก่อนแก้งานเดียวกัน

ลิงก์ admin แข่งขันเดิมพามายัง Dashboard ส่วนผู้สมัครยังใช้ LINE login และดูประวัติที่ [หน้าบ้าน Jaothui Event](https://jaothui-events.vercel.app/) ตามเดิม โซน vote แยกจากงานในคู่มือนี้

## ถ้าเข้าไม่ได้
ตรวจ URL และภาษาที่ใช้พิมพ์รหัสผ่าน ลองเข้าใหม่หนึ่งครั้ง หากยังไม่ได้ให้ติดต่อคุณนนท์ ไม่ส่งรหัสผ่านลงกลุ่มหรือแนบในภาพแจ้งปัญหา เมื่อออกจากเครื่องที่ใช้ร่วมกันให้กด **Logout**
