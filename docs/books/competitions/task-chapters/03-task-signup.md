## ก่อนเริ่ม
เข้า [Dashboard](https://dboard.jaothui.com/) → **จัดการการแข่งขัน** → ค้นงาน → **จัดการงาน** → **ตั้งค่างาน** ให้ผู้จัดยืนยันคำสั่ง ตรวจชื่องาน วันจัด/รับสมัคร และข้อความ **ลงทะเบียนหน้างาน** งานต้องเผยแพร่และยังไม่ปิดหรือจบตามกำหนด

## พักรับผู้ใช้ทั่วไป
1. บันทึกค่าที่กำลังแก้ด้วย **บันทึกการแก้ไข** จนขึ้น **ข้อมูลตรงกับที่บันทึก**
2. กด **ปิดรับสมัคร** อ่านยืนยันว่าปิดรับทั่วไปและเจ้าหน้าที่ยังลงได้จนจบงาน แล้วจึงยืนยัน
3. รอ **อัปเดตสถานะแล้ว** ตรวจ **การรับสมัคร: ปิดรับด้วยมือ** และอ่าน **ลงทะเบียนหน้างาน** แยก ถ้างานยังเข้าเงื่อนไข ต้องระบุว่าเจ้าหน้าที่ลงทะเบียนได้จนสิ้นวันจบงาน

## เปิดกลับตามช่วงวัน
1. ตรวจผู้จัดอนุมัติให้เปิดใหม่ วันเปิด/ปิดรับสมัครยังถูกต้องหรือไม่
2. ถ้าเลยวันปิดรับสมัครแล้ว ให้ขยาย **วันปิดรับสมัคร** ตามที่ยืนยัน แล้ว **บันทึกการแก้ไข** ก่อน อย่าเปลี่ยน **วันที่ใช้ตัดอายุควาย**
3. กด **เปิดรับสมัครตามกำหนด** อ่านยืนยัน รออัปเดต และตรวจสองสถานะ ปุ่มนี้ยังเคารพช่วงวัน ไม่ข้ามเงื่อนไขวันทิ้ง หากวันเปิดอยู่อนาคต **ยังไม่ถึงวันเปิด** เป็นผลถูกต้อง

## จบงานนี้เมื่อ
คำสั่งพักทำให้รับทั่วไปเป็น **ปิดรับด้วยมือ** แต่หน้างานยังอนุญาตตามเงื่อนไข หรือคำสั่งเปิดกลับให้สถานะรับตรงช่วงวันและผู้จัดยืนยัน ทั้งสองกรณีอ่านค่ากลับได้ ไม่มีค่าค้างยังไม่บันทึก

## ช่วยตัวเองและจุดที่ต้องหยุด
ปุ่มปิดอยู่ให้บันทึกค่าค้างก่อน; เปิดแล้วไม่รับให้ตรวจวันเปิด/ปิดและวันจบงาน; ถ้าค้นงานไม่พบให้ล้างตัวกรอง รายการไม่อัปเดตให้โหลดข้อมูลล่าสุดหลังจดค่าที่ยังไม่บันทึก

**ปิดงานด้วยมือ** หรือ **จบตามกำหนด** ไม่มีปุ่มเปิดงานกลับใน flow นี้ อย่าคัดลอกงานเพื่อย้ายผู้สมัครหรือขยายวันเอง ให้คุณนนท์/ผู้ดูแลตรวจแผนผู้จัด กติกาล็อกหรือวันไม่ชัดเป็นเรื่องที่ต้องตัดสิน ไม่ใช่ dev bug โดยปริยาย

ถ้าสถานะอ่านกลับผิดหรือเปลี่ยนสถานะล้มซ้ำหลังตรวจเครือข่าย ให้ผู้ดูแลส่งต่อทีมพัฒนา ระหว่างรออย่าใช้ **ปิดงาน** แทนการพักทั่วไป แนบ URL/รหัสงาน เวลาไทย คำสั่งผู้จัด ขั้นล่าสุด/ผลผิดพลาด ตาม [แบบแจ้งปัญหา](#task-recover) รายละเอียดเสริม: [สถานะงาน](#states)
