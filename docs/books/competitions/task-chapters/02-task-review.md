## ก่อนเริ่ม
เข้าสู่ [Dashboard](https://dboard.jaothui.com/) ด้วยบัญชีทีมงาน เปิด **จัดการการแข่งขัน** → ค้นชื่องาน → **จัดการงาน** → **ใบสมัคร** ต้องมีใบสมัครและเอกสารให้ตรวจ ใช้บัญชีร่วม จึงควรตกลงกันว่าใครรับช่วงรายการใด ระบบไม่ยืนยันชื่อเจ้าหน้าที่รายคน

## 1. หาและตรวจใบสมัคร
ค้นใน **ค้นหาชื่อควาย เจ้าของ หรือไมโครชิพ** ใช้ **สถานะใบสมัคร**, **รุ่นแข่งขัน**, **ชุดรุ่น**, **เพศ**, **สี** ตามต้องการ กด **ตรวจใบสมัคร** ของรายการที่ถูกต้อง ตรวจชื่องาน ชื่อควาย chip วันเกิด **อายุที่บันทึกในใบสมัคร** รุ่น เพศ/สี เจ้าของ/โทร ที่อยู่และรูป ใช้ **เปิดภาพ …** เพื่ออ่านชัด

อายุตัวอย่างฟ้าคราม chip000000261069001 คือ 13 เดือน ณวันตัด 26 ต.ค.2569 ไม่คำนวณทับด้วยวันปัจจุบัน ถ้าข้อมูลเดิมไม่มีอายุหรือหลักฐานไม่ครบให้หยุดสอบถามก่อน Royal ใช้หน้าตรวจร่วมกัน แต่ต้องตรวจภาพที่แนบและเกณฑ์สีของ Royal ให้ตรง ไม่เปลี่ยนฟอร์มงานเพื่อแก้ใบสมัคร

## 2. บันทึกผลพิจารณา
ดู **ผลปัจจุบัน** ใน **ตรวจและอนุมัติ** กรอกหมายเหตุ หากไม่ผ่านต้องกรอก **หมายเหตุ / เหตุผลที่ไม่อนุมัติ (จำเป็นเมื่อไม่อนุมัติ)** เช่น “ภาพด้านข้างอ่านหมายเลขไม่ชัด ขอภาพใหม่ให้ตรวจตรงกับเอกสาร”

กด **บันทึกอนุมัติ** หรือ **บันทึกไม่อนุมัติ** หนึ่งครั้ง รอ **บันทึกผลการตรวจแล้ว การส่ง LINE เป็นขั้นตอนแยกด้านล่าง** ตรวจผลปัจจุบันและเวลาตรวจล่าสุด ใช้ **โหลดข้อมูลล่าสุด** อ่านกลับก่อนส่ง หากมีข้อความที่กำลังกรอกอยู่ให้เทียบกับข้อมูลล่าสุดก่อนบันทึกใหม่

## 3. ส่งข้อความ แล้วอ่านสถานะส่ง
ไป **ผลการส่ง LINE** ตรวจผลที่จะส่งก่อน กด **ส่ง / ลองส่ง LINE** หนึ่งครั้งเมื่อเปิดให้กด รอผล:

| สถานะ | ทำอย่างไร |
|---|---|
| LINE รับคำขอส่งแล้ว | เก็บเป็นผลแจ้งผ่านผู้ให้บริการ ไม่ยืนยันได้รับ/เปิดอ่าน |
| ส่ง LINE ไม่สำเร็จ | ตรวจปัญหาที่แจ้ง ใช้ปุ่มลองส่งจากส่วนนี้เมื่อแก้เหตุแล้ว |
| ยังยืนยันผลส่ง LINE ไม่ได้ / ต้องตรวจผลการส่งก่อนลองใหม่ | หยุดกดซ้ำ ให้ผู้ดูแลตรวจ log/ผลก่อน |
| ไม่มีผู้รับ LINE / ระบบปิดการส่ง LINE อยู่ | ผลพิจารณายังอยู่ แจ้งผู้ดูแลเรื่องช่องทางหรือการตั้งค่า |

**ไม่บันทึกอนุมัติซ้ำเพื่อส่งข้อความใหม่** ไม่ส่งเข้าบัญชีทีมงานแทนผู้สมัคร ภาพในเล่มปิดส่งจริงและใช้ข้อมูลจำลอง จึงไม่ยืนยันว่าข้อความถึงคนจริง

## จบงานนี้เมื่อ
ผลพิจารณาและเหตุผลอ่านกลับถูกต้อง ขั้นแจ้งผลเสร็จเมื่อขึ้น **LINE รับคำขอส่งแล้ว** โดยไม่ต้องให้ผู้สมัครเปิดอ่านต่อหน้าทีม หากไม่มีผู้รับหรือปิดส่ง ให้ระบุว่า “ลงผลแล้ว แต่แจ้งผลค้าง” และส่งต่อผู้ดูแล ไม่อ้างว่าส่งแล้ว

## ช่วยตัวเอง หยุด และส่งต่อ
ค้นไม่เจอให้ **ล้างตัวกรอง** และตรวจชื่องาน; เหตุผลไม่อนุมัติว่างให้กรอกก่อนบันทึก ถ้าชนข้อมูลให้ **โหลดข้อมูลล่าสุด** ตรวจผลเดิม ข้อความที่กรอกยังอยู่

เรื่องเอกสาร/เกณฑ์/ไม่มีผู้รับ/ปิดส่ง ให้คุณนนท์หรือผู้ดูแลตัดสินก่อน ไม่ใช่ dev bug โดยอัตโนมัติ หากอ่านผลกลับไม่ตรง บันทึกล้มซ้ำ หรือสถานะส่งไม่แน่ชัดต้องตรวจ log ให้ผู้ดูแลส่งต่อทีมพัฒนา เก็บ URL+รหัสงาน/ใบสมัคร เวลาไทย ขั้นล่าสุดที่สำเร็จ ผลคาด/จริง error และภาพปิดบังข้อมูล ห้ามส่งรหัสหรือ token ดู [แบบแจ้งปัญหา](#task-recover) หรือ [Royal](#royal) เพิ่มเมื่อจำเป็น
