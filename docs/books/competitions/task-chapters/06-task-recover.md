## ก่อนลองซ้ำ ให้รู้ว่าค้างตรงไหน
คง URL งาน/ใบสมัครไว้ จด **ขั้นล่าสุดที่ยืนยันว่าเสร็จแล้ว** แยกการบันทึกข้อมูลออกจาก LINE และแยก “บันทึกแล้วแต่โหลดงานไม่สำเร็จ” ออกจาก “ยังยืนยันผลบันทึกไม่ได้” อย่ากดซ้ำรัว ๆ เพื่อทดสอบว่าระบบทำงานหรือไม่

## ระดับ 1 — ทีมงานแก้เองได้
| อาการ | ทำอย่างปลอดภัย |
|---|---|
| หางานหรือใบสมัครไม่เจอ | ตรวจชื่องาน/คำค้น → ล้างตัวกรอง → ค้นใหม่ |
| วันที่ไม่ครบ รูปไม่ผ่าน เหตุผลไม่อนุมัติว่าง | แก้ช่องที่ระบบแจ้ง ตรวจรูปชนิด/ขนาดและวันจริง |
| ข้อมูลมีคนแก้ระหว่างเปิดหน้า | จดค่าที่ยังไม่บันทึก → โหลดข้อมูลล่าสุด → เทียบผลก่อนบันทึกใหม่ |
| LINE ส่งไม่สำเร็จแบบทราบผล | แก้เหตุที่แจ้ง แล้วใช้ปุ่มส่ง/ลองส่ง ไม่บันทึกอนุมัติซ้ำ |
| หน้างานสำเร็จ แต่โหลดงานล่าสุดไม่สำเร็จ | ไม่เขียนซ้ำ โหลดหน้าใหม่ก่อนรายถัดไป แล้วตรวจใบเดิม |

**ยกเว้นสำคัญ:** ถ้าหน้างานยังยืนยันผลไม่ได้และมี **ลองคำขอเดิมอีกครั้ง** ให้ใช้ปุ่มนั้นบนหน้าเดิม ห้าม reload/ปิดหน้า/เริ่มคำขอใหม่ คำขอเดิมถูกเก็บในหน้านี้ ถ้ายังไม่แน่ชัดหลังลองคำขอเดิม ให้คงหน้าและส่งต่อ

## ระดับ 2 — หยุดให้คุณนนท์/ผู้ดูแลตัดสิน
เกณฑ์ผู้จัดไม่ชัด, กติกาล็อกหลังมีใบสมัคร, ต้องลงซ้ำโดยมีเหตุจริง, ขอเปิดงานที่ปิดแล้ว, ไม่มีผู้รับ LINE หรือระบบปิดส่ง เป็นเรื่องสิทธิ์/การตั้งค่า/การตัดสินของผู้จัดก่อน ไม่ใช่ dev bug อัตโนมัติ ทีมไม่แก้ config หรือฐานข้อมูล และไม่เปิด admin เก่ากลับเอง

## ระดับ 3 — ผู้ดูแลส่งต่อทีมพัฒนา
- ข้อมูลที่บันทึกอ่านกลับไม่ตรง หรือใบสมัคร/ไฟล์เป็นอีกงาน
- โหลด/บันทึก/ส่งออกล้มซ้ำหลังทำการกู้ที่อนุญาตและตรวจอินเทอร์เน็ตแล้ว
- อายุ/รุ่นยังผิดหลังตรวจวันเกิด วันตัดอายุ สี Royal และขอบเขตรวม/ไม่รวมครบ
- ผลเขียนหรือส่ง LINE ไม่แน่ชัด/ต้องตรวจผลก่อนลองใหม่ ต้องตรวจ log ก่อนส่งซ้ำ

## แบบแจ้งเหตุ: คัดลอกแล้วกรอก
- **สิ่งที่ต้องการทำ:** …

- **ชื่องาน / รหัสงาน / URL:** …

- **รหัสใบสมัคร / URL (ถ้ามี):** …

- **เกิดเมื่อ (วันและเวลาไทย):** …

- **ขั้นล่าสุดที่ยืนยันแล้ว + ผลที่เห็น:** …

- **คาดว่าจะเห็น / สิ่งที่พบจริง:** …

- **ข้อความผิดพลาดตามหน้าจอ:** …

- **ลองวิธีใดแล้ว และผลแต่ละครั้ง:** …

- **ภาพหน้าจอปิดบังข้อมูลที่ไม่เกี่ยวข้อง:** …

ส่งให้ **คุณนนท์/ผู้ดูแล** ระบุว่าต้องการคำตัดสินงานหรือส่งต่อทีมพัฒนาตามระดับข้างต้น ห้ามส่งรหัสผ่าน key token หรือข้อมูลส่วนตัวเกินจำเป็น หากไม่รู้รหัสใบสมัครให้บอกว่าไม่มี อย่าบันทึกใหม่เพื่อสร้างรหัสสำหรับแจ้งเหตุ

## จบงานนี้เมื่อ
อาการที่แก้เองได้กลับเป็นผลถูกต้องและอ่านกลับยืนยันแล้ว หรือผู้ดูแลได้รับข้อมูลครบ รับช่วง และทราบว่าหน้า/คำขอใดต้องคงไว้ เรื่องที่ส่งต่อยังไม่ถือว่าระบบแก้เสร็จ จดสิ่งที่ต้องตรวจกลับเมื่อผู้ดูแลแจ้งพร้อมใช้งาน
