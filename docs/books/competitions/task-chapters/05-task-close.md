## เลือกสิ่งที่ต้องทำก่อน
- **ต้องการไฟล์อย่างเดียว:** ไม่ต้องปิดงาน เข้า [Dashboard](https://dboard.jaothui.com/) → **จัดการการแข่งขัน** → ค้นงาน → **จัดการงาน** แล้วไปขั้น **2. ส่งออกไฟล์** ได้ทันที งานที่ยังเปิดอยู่ส่งออกได้ตามปกติ
- **ต้องการปิดงานด้วย:** ให้ผู้จัดยืนยันหยุดรับทั้งผู้ใช้และเจ้าหน้าที่ ตรวจคำขอหน้างานที่ยังไม่แน่ชัด อย่าปิด/โหลดหน้าคำขอที่ยังไม่ยืนยันผล ให้ผู้ดูแลรับช่วงก่อน เข้า **ตั้งค่างาน** ของงานที่ถูกต้องและบันทึกค่าค้าง จากนั้นทำขั้น1

ถ้าผู้จัดต้องการพักเฉพาะทั่วไป ให้ใช้ [พักรับทั่วไป](#task-signup) แทน อย่าปิดงานเพียงเพื่อดาวน์โหลดไฟล์

## 1. เฉพาะเมื่อต้องปิดงานทุกช่องทาง
1. กด **ปิดงาน** อ่าน **ปิดงานและหยุดรับสมัครทุกช่องทาง** แล้วจึงยืนยัน
2. รอ **อัปเดตสถานะแล้ว** ต้องเห็น **ปิดงานด้วยมือ** และหน้างานไม่อนุญาตรับใหม่ หากเป็น **จบตามกำหนด** เพราะพ้นวันจบงานอยู่แล้ว ก็หยุดหน้างานตามกำหนด ไม่ต้องพยายามเปิดกลับ
3. ประวัติและส่งออกยังอ่านได้ ปิดงานไม่ได้หมายถึงซ่อนงานหรือประวัติจากหน้าบ้าน และไม่มีปุ่มเปิดงานที่ปิดด้วยมือกลับใน flow นี้

## 2. ส่งออกไฟล์ — ทำได้ทั้งงานเปิดและปิด
กด **ส่งออกข้อมูล** ตรวจ **จำนวนใบสมัคร** และ **วันตัดอายุของงาน** ไฟล์รวมทุกสถานะ รอตรวจสอบ/อนุมัติแล้ว/ไม่อนุมัติ ไม่ได้จำกัดตามตัวกรองหน้าใบสมัคร

![ตัวเลือกส่งออก](asset:export-options)

เลือก **ดาวน์โหลด Excel** ได้ XLSX แยกชีตตามรุ่น สี เพศ ชุดรุ่น หรือ **ดาวน์โหลดใบสมัคร DOCX (ZIP)** ได้ ZIP ใบสมัครรายตัวและข้อมูลงาน รอข้อความสร้างไฟล์แล้วเปิดจากโฟลเดอร์ดาวน์โหลด แตก ZIP ก่อนใช้ DOCX

## 3. ตรวจไฟล์ก่อนส่งต่อ
ตรวจชื่องาน จำนวนรวม รายการชื่อ/chip รุ่น สถานะ และอายุ ไฟล์ใช้อายุที่บันทึกไว้ก่อน รวม 0 เดือน ถ้าไม่มีจึงคำนวณจากวันเกิดกับวันตัดอายุของงาน พร้อมหมายเหตุ ไม่ใช้วันดาวน์โหลดและไม่จัดรุ่นย้อนหลัง ถ้าไม่มีใบสมัคร ระบบส่งไฟล์สรุปว่าไม่มีข้อมูลได้

## จบงานนี้เมื่อ
> - **เอาไฟล์อย่างเดียว:** ไฟล์ที่ต้องส่งเปิดได้ ตรวจชื่องาน จำนวน สถานะและอายุแล้ว สถานะเปิด/ปิดงานยังเหมือนก่อนเริ่ม ไม่เปลี่ยนเพื่อทำไฟล์
> - **ปิดงานด้วย:** งานหยุดรับทุกช่องทางตามผู้จัดยืนยัน และไฟล์ผ่านการตรวจข้างต้น ส่งเฉพาะผู้เกี่ยวข้องเพราะมีชื่อเจ้าของ/โทรศัพท์

## แก้เอง หยุด หรือส่งต่อ
โหลดไม่ได้ให้ตรวจอินเทอร์เน็ตแล้วลองดาวน์โหลดใหม่หนึ่งครั้ง ตรวจว่าเบราว์เซอร์เก็บไฟล์ไว้ที่ใด ถ้ามีหมายเหตุข้อมูลอายุไม่ครบ ให้คุณนนท์/ผู้ดูแลตรวจข้อมูลเดิม ไม่แก้ตัวเลขในไฟล์แล้วถือว่าระบบถูกแก้

กดปิดผิดหรือผู้จัดเปลี่ยนใจ ให้หยุดและแจ้งคุณนนท์/ผู้ดูแล ไม่มีปุ่มเปิดกลับ ไม่สร้างสำเนาเพื่อย้ายผู้สมัคร หากสถานะอ่านกลับผิด ไฟล์ผิดงาน จำนวนผิดซ้ำหลังตรวจงาน/เวลาข้อมูล หรือดาวน์โหลดล้มซ้ำ ให้ส่งต่อทีมพัฒนา พร้อม URL+รหัสงาน เวลาไทย ขั้นล่าสุดที่สำเร็จ ชื่อไฟล์ ผลคาด/จริง error และภาพปิดบังข้อมูล อย่าแนบไฟล์ผู้สมัครเต็มชุดลงกลุ่มทั่วไป รายละเอียด [ส่งออก](#export) และ [แบบแจ้งปัญหา](#task-recover) เป็นตัวช่วยเสริม
