# วิธีใช้งานทะเบียนควายและรายการค้าง

เอกสารนี้อธิบายระบบรุ่นใหม่ที่ผ่านการทดสอบในเครื่องแยกเท่านั้น การเปิดใช้จริงยังต้องผ่านการทดสอบสภาพแวดล้อมปลายทางและอนุมัติการเปิดระบบค่ะ

## เพิ่มควาย

เข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่เดิม กรอกไมโครชิป15หลักและข้อมูล เลือกรูป JPEG/PNG ขนาดน้อยกว่า2 MB แล้วตรวจร่าง กด Mint NFT ครั้งเดียว รอรายการเดิมแสดงว่ายืนยันแล้วจึงกด Mint Metadata ระบบบันทึก token จากธุรกรรมจริงและตรวจข้อมูลก่อนเผยแพร่ทะเบียน ห้ามกด Mint ใหม่เพื่อซ่อมข้อมูลที่ยังไม่สำเร็จ

หากหน้าเว็บปิด อินเทอร์เน็ตขาด หรือออกจากระบบ ให้เข้าสู่ระบบใหม่และเปิดรายการเดิม รายการและธุรกรรมยังอยู่ กดดำเนินการต่อโดยใช้รายการเดิม ระบบอาจต้องรอยืนยันหรือให้ผู้ดูแลตรวจสอบ ห้ามสร้างรายการใหม่เพื่อข้ามคำเตือน

## แก้ไขข้อมูล

ค้นหาไมโครชิป เปิดรายละเอียด กดช่องที่ต้องการแก้ไข ปรับค่าแล้วกดยืนยันหนึ่งครั้ง ระบบตรวจข้อมูลปัจจุบันและบันทึกคำขอนั้น หากเปิดหน้าต่างทิ้งไว้จนข้อมูลเปลี่ยน ระบบจะหยุดและเก็บค่าที่กรอกไว้ ให้ปิดแล้วค้นหาข้อมูลล่าสุดก่อนตัดสินใจอีกครั้ง

แก้เฉพาะช่องที่ต้องการ พ่อและแม่ที่ไม่ได้เปลี่ยนจะคงค่าเดิม ข้อมูลเก่าบางส่วนอาจต่างกันระหว่างทะเบียนกับบล็อกเชน ระบบแสดงความต่างและไม่เปลี่ยนช่องอื่นเงียบ ๆ หากตัวตนของทะเบียนไม่ตรงกับ NFT จะยังอ่านข้อมูลได้ แต่แก้ไขไม่ได้ ให้ผู้ดูแลตรวจสอบก่อน

การเปลี่ยนบางช่องต้องบันทึกทั้งชุดบนสัญญาเดิมและคืนค่า DNA ภายหลัง ระหว่างนั้นหน้าอาจยังแสดงข้อมูลทะเบียนเดิม ให้ดำเนินการต่อรายการเดิมจนเสร็จ ห้ามแก้ซ้ำเพื่อชดเชย DNA หรือ Mint ใหม่ รูปและไฟล์ NFT จะเผยแพร่เมื่อผ่านการตรวจแล้วเท่านั้น

## เมื่อพบข้อความหยุด

- ระบบพักรับคำขอใหม่: เก็บรายการเดิมไว้ รอผู้ดูแลเปิดระบบ รายการที่ส่งธุรกรรมแล้วอาจดำเนินการต่อได้
- เซสชันหมดอายุ: เข้าสู่ระบบใหม่แล้วเปิดรายการเดิม ไม่ต้องกรอกหรือ Mint ซ้ำ
- ยังตรวจสอบประวัติไม่ได้: แจ้งผู้ดูแลพร้อมหมายเลขรายการและ hash ที่แสดง ห้ามส่งรหัสผ่านหรือข้อมูลลับ
- ข้อมูลเปลี่ยนหรือหลักฐานขัดแย้ง: หยุดคำขอนั้น ให้ผู้ดูแลตรวจทะเบียนกับบล็อกเชนก่อน ไม่ควรพยายามแก้ทุกช่องให้เหมือนกันเอง
- อัปโหลดไม่ครบ: ลองอัปโหลดไฟล์เดิมในคำขอเดิม หรือยกเลิกเฉพาะคำขอที่ยังไม่ได้ส่ง ระบบไม่อนุญาตยกเลิกรายการที่มีธุรกรรมลงนามแล้ว

เมื่อระบบแสดงว่าสำเร็จ ให้เปิดรายละเอียดจากข้อมูลล่าสุดอีกครั้ง ตรวจช่องที่แก้ รูปและ DNA หากยังโหลดไม่ได้ ให้ลองดึงข้อมูลใหม่ในรายการเดิมและแจ้งผู้ดูแลค่ะ
